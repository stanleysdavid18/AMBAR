# ÁMBAR 🤖

> Un asistente inteligente modular desarrollado en Python.

## Descripción

Ámbar es un asistente de inteligencia artificial diseñado para conversar de forma natural, ejecutar tareas, recordar información y ayudar al usuario mediante voz, automatización e inteligencia artificial.

## Estado del proyecto

🚧 En desarrollo (Pre-Alpha)

## Objetivos

- Conversación natural.
- Voz (escuchar y hablar).
- Memoria persistente.
- Automatización de Windows.
- Arquitectura modular.
- Fácil de ampliar mediante nuevos módulos.

---

Proyecto desarrollado como parte de un proceso de aprendizaje y construcción de un asistente inteligente desde cero.
